# Зачем делить бизнес-логику и инфраструктуру

Бизнес-логика описывает процесс станции: состояния, переходы и инварианты. Купить материал, хранить чертёж, произвести. Это прямое отображение процесса, как он есть у станции.

Инфраструктуры в этом процессе нет. Она нужна приложению: ORM, SQL, HTTP DTO, обработчики, внедрение зависимостей, брокер, менеджер транзакций, лог, кэш, клиенты внешних API. Замена базы или HTTP не меняет инвариант.

Инвариант клади в агрегат. Правило «нельзя забрать больше, чем есть на складе» остаётся в `Station`, пока живут и SQL, и обработчик.

Правила: [справочник](ddd-reference.md). Шаги: [инструкция](ddd-howto.md). Расчёт склада, чертежа и производства: [домен станции](station-domain.md). Структура берётся из справочника. Если код ей противоречит, верен справочник.

## Агрегат — одна транзакция

`Station` — агрегат станции и граница транзакции. Склад, чертежи и производство сохраняются одним `save` либо не сохраняются. Свой `save` у склада разрывает границу: в базе останется производство без списания или списание без выпуска.

Снаружи состояние меняет только метод корня. Вызов метода вложенной части обходит проверку, которую корень делает для всех частей вместе.

Агрегат держат маленьким. Чужой агрегат внутрь не вкладывают. В поле лежит его ID. `MaterialID` называет материал и не переносит в станцию чужое состояние.

## Сервис

Агрегат базу не открывает. Иначе инвариант смешивается с SQL.

Сервис — бизнес-код. Он принимает команду, загружает агрегаты и сохраняет их. Один агрегат: загрузить станцию, вызвать `Station.Take`, сохранить станцию. Доменная ошибка обрывает сценарий до записи.

Сценарий на несколько агрегатов в корень не кладут. Корень соседей не загружает. Его собирает сервис и каждый агрегат трогает только методом корня.

## Репозиторий и version

Интерфейс репозитория идёт вместе с агрегатом. Реализация в инфраструктуре собирает объект из базы и разбирает его обратно. Сборка из базы — единственное место, где код снаружи агрегата пишет в его поля.

`version` показывает, та же ли строка в базе, что локальная копия. Без поля два сохранения молча затирают друг друга.
